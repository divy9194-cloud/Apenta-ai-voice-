Penta AI Voice Assistant

An advanced cross-platform voice assistant powered by Gemini AI and Flutter

Developed by Divyanshu Kumar

Overview

Penta is a feature-rich, intelligent voice assistant built using Flutter for mobile and Android overlay integrations. It connects voice recognition, text-to-speech, Google Gemini AI, Firebase Authentication, and native device actions into a seamless user experience.

Core Features

AI Chat & Voice

Powered by Google Gemini gemini-2.5-flash for quick, contextual multilingual answers in English, Hindi, and Hinglish.

Device & App Control

Native Kotlin bridge integration to execute device-level commands, open installed applications, and manage screenshots/mic services.

Image Generation

Create AI-generated images directly within the app interface using dedicated generative image models.

Music & Media

Integrated YouTube Music playback capability with automatic top result lookup.

Firebase Backend

Secure user authentication and cloud data storage managed via Firebase Auth and Firestore.

Permission Disclosure

Transparent permission handling for microphone, accessibility, and background services.

Tech Stack

Framework: Flutter (Dart SDK >=3.3.0)

AI & Services: Google Gemini API, Firebase (Auth, Core, Firestore), Speech-to-Text, Flutter TTS

Platform: Android (Kotlin native bridges for overlay and accessibility services)
